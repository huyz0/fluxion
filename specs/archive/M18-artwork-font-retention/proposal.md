# Exact artwork-font retention

M18.81 completes FR-LIB-004, FR-AST-003 and NFR-LIC-003 for imported artwork whose font is absent from the document theme. The production paint witness already qualifies the original SVG corpus; bytes, rights and offline ownership still need transport.

WHEN a used imported definition needs a font THE SYSTEM SHALL acquire its exact licensed bytes before effects and retain its complete used face/resource/credit closure through archive and inline save/reopen. IF bytes, rights, identity or readiness are invalid THE SYSTEM SHALL refuse atomically rather than substitute another family. WHEN a source family collides with ordinary text THE SYSTEM SHALL render both with their own verified bytes. Old 1.0 packs and ordinary document fonts retain their behavior.

Scope is the existing pinned Inter400normalASCII artwork profile, versioned pack metadata, bounded acquisition, persistence and strict host registration. Arbitrary profiles, font subsetting/WASM, pack-import command grammar and interactive library UI remain their existing separate rows.
