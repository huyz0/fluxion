Editing essentials (M7): a keymap of editor commands with rebinding, a shortcut cheat sheet, a command palette (Ctrl/Cmd+K) and context menus (with select same type and select same style); a screens panel and undo/redo that restore the screen, camera and selection; inline rich-text editing with Markdown shortcuts; a schema-driven inspector (mixed values, scrubbing, colour and token pickers, enum icons, gradient previews, arrow-key steps) and parametric and connector handles; the internal, cross-document and system clipboard (images and sanitised SVG); and a Problems tab with fixes.
