## Goal

The library covers real diagram work. Shape definitions are declarative JSON packs with
licence and attribution; twelve first-party packs ship (flowchart, UML, BPMN-lite, network,
cloud architecture, icons, …). Users import SVGs, Iconify collections and draw.io libraries as
shapes, save their own "My shapes", and swap a shape's definition without losing text, style or
connections. Packs load lazily and a saved file embeds only the definitions and font glyphs it
uses. Packs can contribute custom connector types.

## Decide before coding

- **ADR-0048 Shape pack format v1** — pack JSON schema (outline template or geometry fn id,
  anchors, text regions, handles, default size/style, keywords, category, `license`,
  `attribution`), split index (`index.json` metadata) vs. per-category geometry files, def
  embedding in saved files.
- **ADR-0049 Shape import pipeline** — SVG sanitize (NFR-SEC-001 corpus), outline derivation
  (union of filled paths → outline; bbox fallback), default anchors, colour → token mapping;
  Iconify JSON mapping; draw.io `mxlibrary`/stencil XML conversion; existing bounded ZIP/DEFLATE codec
  (ADR-0153), not the original fflate hypothesis.
- **ADR-0050 Pack licence & attribution policy** — required fields, allowlist of pack licences,
  brand/cloud icon usage rules, attribution embedded in files that use a pack.
- **ADR-0051 Font subsetting engine** — direct HarfBuzz subset WASM plus bounded
  standalone Google WOFF2, lazy in studio/CLI and absent from the player;
  reproducible assets/CSP probes in M18.48 precede integration; subset hash feeds layout fingerprint.

## Scope / Non-scope

- In: `packs/*` listed below, pack schema + validator, lazy index/geometry loading, importers in
  `packages/editor` (library) + CLI `fluxion pack-import` helper, My shapes local pack, replace

- Out: remote pack registries (FR-LIB-010, M26); `.fluxpack` code plugins (M27); PPTX/draw.io
  *document* import (M31).
