# M13 — Layout engine v1

| Increment | Depends on | Completion command |
|---|---|---|
| R2 | M12 | `node scripts/gates/m13-complete.mjs` |

## Goal

Diagrams arrange themselves. `@fluxion/layout` exposes a pluggable, deterministic layout
pipeline (snapshot → place → pins → overlap → snap) with the built-ins `layered` (dagre),
`grid` and `stack`, runs in a worker with cancellation, supports nested containers bottom-up,
and guarantees zero overlap. The FluxScript compiler uses it for every unpinned element, the
editor gains an "Arrange" command for screen / selection / container, and saved files carry
baked positions only — no layout code in the player.

## Requirements

FR-LAY-001 (part — CLI surface lands in M14 `fluxion layout`), FR-LAY-002, FR-LAY-004 (part —
label-vs-shape avoidance lands with the router label pass in M16), FR-LAY-005, FR-LAY-007,
FR-LAY-008, FR-DOC-007, NFR-PERF-005 (layout part; routing 200 connectors < 300 ms lands in

## Decide before coding

- **ADR-0033 Layout engine contract v1** — `LayoutAlgorithm`/`LayoutEngine`/`LayoutInput`/
  `LayoutOutput` from architecture 05 §2 frozen as the registry contract; worker message
  protocol (`{id, revision, algId, input, seed}`, last-write-wins, cancel); `fingerprint`
  composition incl. font-subset hash.
- **ADR-0034 Overlap removal and determinism** — VPSC from WebCola as the overlap post-pass vs.
  own sweep; sfc32 seeded PRNG; canonical ordering by (`order`, id); 0.5 px quantization; fixed
  iteration counts.
- References ADR-0005 (layout/routing stack, permissive defaults).

## Scope / Non-scope

- In: `packages/layout` (+ `layout/worker`), snapshot builder from records, `grid`, `stack`,
  `layered` via `@dagrejs/dagre`, post-passes `pins`/`overlap`/`snap`, nested containers,
  `semantic` data typing, `arrange` command, editor Arrange UI, DSL `layout:` wiring, benches.
- Out: tree/force/radial/mindmap/timeline/swimlane, constraints, incremental mode, live
  containers, tidy, fit, templates (M17); orthogonal obstacle routing and label placement (M16);
  layout animation (M22); ELK pack (M17).
