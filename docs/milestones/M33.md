# M33 — 1.0 release: API & format freeze, docs, gallery — **R8 exit**

| Increment | Depends on | Completion command |

## Goal

Fluxion 1.0 ships. The public TypeScript APIs and the file format v1 are frozen, with published
API reports and schema fixtures that later versions must honour. The docs site is complete (user,
author, plugin, API, CLI/MCP, format spec), including `llms.txt`, and a gallery of 10 example
documents is live. Plugins can be signed by publishers and discovered through a static registry
index. Sites can span several documents. Every increment's exit criteria are re-verified, and
the 1.0 packages are released with changesets and npm provenance.

## Requirements

FR-PKG-005, FR-SITE-005, NFR-MNT-007 (freeze), NFR-PORT-003 (v1 compatibility policy),
exit criteria of R0–R8 (`01-scope-and-increments.md` §2).

## Decide before coding

- **ADR-0133 File format v1 freeze.**
  - `formatVersion` 1 and `schemaVersion` 1.0.0.
  - Frozen `.flux`, `.flux.html` and `.flux.json` fixtures.
  - The JSON Schema is published at a stable URL.
  - Post-1.0 rules: minor changes are additive only, major changes need a converter and an ADR,
    and deprecated fields keep being read.
- **ADR-0134 Public API 1.0 policy.**
  - Lists which packages go 1.0 as `@public`: `schema`, `core`, `format`, `dsl`, `player`, `sdk`,
    `cli` and `mcp`, plus the tool schemas.
  - Lists what stays `@beta` or `0.x`.
  - The deprecation window.
  - A major changeset plus an ADR is required for any break.
- **ADR-0135 Plugin signing.**
  - Publisher keys are Ed25519 (WebCrypto, with `@noble/ed25519` (MIT) as a fallback).
  - `signature.json` signs `integrity.json`.
  - Keys live in the registry index, together with a revocation list and a rotation procedure.
  - The trust UI shows the publisher.
- **ADR-0136 Multi-document site manifest.** `fluxion.site.yaml` defines documents, routes,
  shared navigation and search, and cross-document links (`goto: other.flux#screen`).
- Reference: ADR-0003 (format), ADR-0007 (trust), ADR-0112/0074 (registry index, pack integrity).
