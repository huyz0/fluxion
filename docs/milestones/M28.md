## Goal

The component contract carries real content. There is a themed data chart (bar, line, pie,
area), plus code blocks, math, QR codes and sandboxed web embeds. Element properties can bind to
safe expressions over variables and semantic data, for example `fill = vars.ok ? theme.success :
theme.danger`, and a hard budget stops runaway expressions. Themes gain glass, neumorphic and
hand-drawn (seeded rough.js) looks, and authors get find & replace. R6 closes when a third-party
pack (`examples/packs/acme-charts`: shapes, a React chart component and a layout) is installed,
embedded in `examples/r6-plugin-demo.flux.html`, and runs sandboxed from `file://`.

## Decide before coding

- **ADR-0116 Data binding model.**
  - `element.bindings: { [propPath]: Expr }`.
  - The evaluation context: `vars`, `semantic`, `theme`, `screen` and `step`.
  - Precedence: bindings resolve after state and breakpoint patches.
  - Signal-driven recompute.
  - Errors surface as diagnostics and fall back to the base value.
- **ADR-0117 Embed and chart libraries.**
  - Charts are our own SVG, built on `d3-scale` and `d3-shape` (ISC). Recharts is rejected
    because of its size.
  - Code is highlighted with **Shiki** (MIT, JS regex engine) at edit and save time and stored
    as tokens, so the player carries no grammar.
  - Math uses **KaTeX** (MIT), with fonts embedded only when used.
  - QR codes use **uqr** (MIT).
  - Web embeds are iframes with `sandbox`, turned off offline.
  - The ADR records licence-gate results and the size of each chunk.
- **ADR-0118 Sketch and surface effects.** Sketch rendering uses **roughjs** (MIT) with a seed per
  element for determinism. The ADR maps glass and neumorphism to token-driven filter and shadow
  presets and records their performance-tier fallbacks.

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Shiki/KaTeX weight leaks into files that don't use them | NFR-SIZE-003 fixture grows | Tokens stored in props; KaTeX CSS/fonts embedded per use only; size test per embed |
| Binding recompute storms on variable changes | Frame drops with many bound elements | Per-binding computed signals; bench 500 bindings recompute < 4 ms |
| Web embeds break offline promise (NFR-PORT-002) | Network-blocked E2E makes requests | Embeds disabled by default in offline mode; explicit per-doc allow |
