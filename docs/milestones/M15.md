# M15 — MCP server, AI assistant & evals — **R2 exit**

| Increment | Depends on | Completion command |
|---|---|---|
| R2 | M14 | `node scripts/gates/m15-complete.mjs` |

## Goal

R2 ships: an LLM produces a valid 10-screen deck from a prompt via MCP, and it opens in the
editor. `@fluxion/mcp` exposes the CLI operations as MCP tools, resources and prompts over stdio
and streamable HTTP. The studio gets an AI assistant panel (provider adapters, diff preview,
one-undo apply). A provider-agnostic generation pipeline (outline → streamed screens → validate
→ repair → layout → lint) is measured by `pnpm eval` against recorded responses. Mermaid and
Markdown import produce FluxScript, and external asset URLs can be embedded on save.

## Requirements

FR-MCP-001, FR-MCP-002, FR-EDT-014, FR-AI-007, FR-AI-009, FR-DSL-007, FR-IMP-001, FR-IMP-002,
FR-AST-006, NFR-AI-001, NFR-AI-004, NFR-SEC-004, NFR-A11Y-006, NFR-PORT-004. Completes
FR-AI-004 (eval part from M14) and FR-AI-011 (MCP resources part from M14).

## Decide before coding

- **ADR-0038 MCP server model** — `docHandle` sessions, allowed file roots, stdio vs streamable
  HTTP (127.0.0.1 bind, origin check), tool result shapes (diagnostics + revision), image content
  for `render_screen_png`.
- **ADR-0039 Eval harness** — case schema, recording key `hash(case + prompt version + model)`,
  reference model, scorecard metrics; alt-text / reading-order metric defined, threshold set from
  the first recorded baseline (NFR-A11Y-006 has no number — not invented).
- **ADR-0040 Mermaid & Markdown import** — parsing strategy (lazy `mermaid` parser vs. hand-written
  subset for flowchart/sequence-lite/mindmap/timeline/class-ER), `mdast-util-from-markdown` for
  Markdown; both emit FluxScript.
- **ADR-0041 Provider adapters & key storage** — `LlmClient` port, adapters in
  `apps/studio/src/ai/`, IndexedDB key store with optional passphrase encryption (WebCrypto).

## Scope / Non-scope

- In: `packages/mcp`, generation orchestrator in `packages/dsl/src/generate/`, prompts in
  `packages/dsl/prompts/`, `eval/` cases + recordings + scorecard, AI panel, adapters, importers,
  external asset refs, CI OS matrix for CLI/MCP, R2 exit checklist and demo.
- Out: MCP live link to open studio tab (FR-MCP-003, M25); generation modes beyond deck/diagram
  (FR-AI-008, M23); PPTX/draw.io importers (M31).

| Risk | Signal | Mitigation |
|---|---|---|
| Recorded evals overfit prompts; live nightly lower | live scorecard < recorded by > 5 pts | Nightly live job files an issue; refresh recordings only via stated task |
| `mermaid` parser needs DOM / is too heavy | import fails in Node or chunk > 1 MB | ADR-0040 fallback: hand-written subset parser for the five diagram kinds |
| MCP SDK / client behaviour differs between Claude Code and Codex | demo transcript works in one client only | Keep tools schema-simple; test both clients in task 18 before exit |
| One-shot validity below 90 % | first scorecard < threshold | Improve cheat sheet + did-you-mean; do not lower threshold (check-drift) |
