# M7 — Editing essentials: text, inspector, clipboard, commands

| Increment | Depends on | Completion command |
|---|---|---|
| R1 | M6 | `node scripts/gates/m7-complete.mjs` |

## Goal

The editor becomes productive. Users can undo and redo any change (the view follows across
screens), edit rich text in place with Markdown shortcuts, and tune properties in an
inspector generated from the schema that handles mixed multi-selections. They can drag
parametric handles and connector handles, and copy/paste within and across documents. Every
command is reachable from the Ctrl/Cmd+K palette, a rebindable keymap and context menus. A
validation panel lists document problems and offers one-click fixes.

## Requirements

FR-EDT-006 (UI; core in M3), FR-EDT-007 (part: Mermaid paste lands with FR-IMP-001 in M15),
FR-EDT-008, FR-EDT-011, FR-EDT-012, FR-EDT-013, FR-EDT-021, FR-TXT-001, FR-TXT-002,
FR-TXT-003, FR-TXT-004, FR-CON-007, FR-SHP-003 (handles + inspector; model in M5).

## Decide before coding

- ADR-0064: rich-text editor library (ProseMirror/Tiptap vs Lexical). Constraints: it must
  read and write the ProseMirror-compatible JSON subset from ADR-0013, load only in the editor
  bundle (never the player), support input rules for Markdown, and have a permissive licence.
- ADR-0020: clipboard format and cross-tab strategy. Covers the async Clipboard API
  `web application/x-fluxion+json` custom format, the `text/html` `<template data-fluxion>`
  fallback, and asset inlining (≤ 1 MB).

## Scope / Non-scope

- In: undo UI and view restore, rich-text rendering and editing, browser and Node measurers,
  inspector generator, param handles, connector handles, clipboard (internal + system image/SVG/
  text), command palette, keymap + cheat sheet, context menus, validation panel with
  `lintRules`.
- Out: find/replace (R6), text animations (R4), text fields (R4), Mermaid/Markdown import
  (M15), anchor-snapping polish (M16), grouping/align (M8).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Rich-text library's model diverges from the schema subset | round-trip test loses marks/attrs | Strict schema mapping layer with a property round-trip test; reject unsupported nodes on paste |
| Async Clipboard custom formats unsupported in Firefox/Safari | cross-doc paste fails on webkit/firefox | ADR-0020 fallback via `text/html` template; test per browser |
| Inspector generator can't express some widgets | hand-written panels creep in | Allow registered `inspectors` overrides per kind (the same path plugins use) |

- **Grow on text edit (M5 final F3):** the command that edits a shape's text applies `fitShapeText`'s grow height in the same transaction when the shape's `textFit` is `grow` (ADR-0018 item 4), with an E2E that edits text and sees the shape grow; M5 only fits text when drawing, and its ±1 px test patches the height itself.
