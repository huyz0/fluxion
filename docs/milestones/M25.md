## Goal

The viewer can move through a diagram in space as well as in sequence. Clicking a node zooms
into its sub-screen, a breadcrumb leads back out, and screens can switch between named states
with animation. An explore mode supports panning, focusing and reading details. Presenters get
a synced speaker window, remote control from a phone, rehearsal timings, and live tools (laser,
spotlight, ink, lens, blackout). Authors can wire interactions visually and watch rules fire in
a debugger. An MCP agent can edit the open studio document live. R5 closes with
`examples/r5-system-map.flux.html`.

## Decide before coding

- **ADR-0106 Spatial camera and sub-screens.** A sub-screen is a `screen` record with
  `parentShapeId`, and the model tweens a camera from the shape box to the full canvas. The
  breadcrumb stack shares `history` with branching navigation. The ADR also defines the deep-link
  form `#/<screen>/<sub>/<group>`.
- **ADR-0107 Speaker sync and remote control.** Sync uses BroadcastChannel with a `postMessage`
  fallback (07 §4.6). The phone connects through a LAN relay started by `fluxion present
  --remote`, using a WebSocket and a one-time pairing token shown as a QR code (`uqr`, MIT). A
  fallback pairs over WebRTC with manual signalling through QR offer and answer. There is no
  cloud service, and the ADR includes a threat note.
- **ADR-0108 MCP live link.** The server listens only on a `127.0.0.1` WebSocket and checks a
  random token and the origin. A patch applies as one undoable transaction, and the user sees an
  attach prompt. The studio is always the one that initiates the connection.
- **ADR-0109 Quiz/poll before the component contract.** These ship as `packs/interactive` element
  kinds through the internal registries, and are ported to the public component contract in M27
  (FR-CMP-001).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| LAN relay blocked by firewalls or corporate networks | Remote E2E passes but manual smoke fails | WebRTC QR pairing fallback; document limits; feature is S-priority |
| Zoom-into with deep nested content drops frames on mobile | Mobile trace p90 > 20 ms | Preload sub-screen; tier down to crossfade; raster snapshot during zoom |
| MCP live link as an attack surface (local web pages reaching the socket) | Security review finding | Loopback only, token, Origin allowlist, user attach prompt (ADR-0108) |
