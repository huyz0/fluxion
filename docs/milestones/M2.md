| Increment | Depends on | Completion command |

## Goal

`@fluxion/schema` defines every record type of the document model as Zod 4 schemas. It
provides stable IDs, fractional indices, validation with JSON-pointer diagnostics, canonical
serialization, a migration framework, and preservation of unknown data. `@fluxion/geometry`
provides the pure math the engine, renderer and router build on. Both packages are
deterministic, property-tested and at ≥ 90 % / 85 % coverage. Other packages build documents
through test builders instead of hand-written JSON.

## Requirements

FR-DOC-001, FR-DOC-002, FR-DOC-003, FR-DOC-004, FR-DOC-005 (part: preservation; placeholder
render in M4), FR-DOC-010, FR-SCR-001 (part: model; render in M4), FR-SHP-001 (part: model +
transform math; render in M4), FR-CON-001 (part: model; render in M4), NFR-REL-002 (part:
document parse; container loader in M10), NFR-REL-005.

## Decide before coding

- ADR-0002 (record store + signals, CRDT-ready) is the reference.
- ADR-0012: ID and ordering primitives. Covers `nanoid(16)` through the `Random` port, and
  fractional-index keys (an own implementation vs `fractional-indexing`) including key-length
  growth and rebalancing.
- ADR-0013: rich-text JSON subset. The ProseMirror-compatible node/mark set is defined as Zod
  and validated without an editor library, which is chosen in M7 (ADR-0019).

## Scope / Non-scope

- In: record schemas (document, screen, element kinds shape/connector/group/frame/text/image/
  component, binding, asset, theme stub, timeline, step, interaction, variable, plugin-ref,
  comment), AnchorRef, Style/TokenRef, diagnostics, serialization, migrations, lenient repair,
  builders + fast-check arbitraries, shared fixtures, and geometry (Vec2, Mat2d, Box, Path,
  PathSampler, intersections, SpatialIndex).
- Out: store and commands (M3), rendering (M4), the file container (M10), and JSON Schema
  export for AI (M14).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Zod strips unknown keys by default, so data is silently lost | FR-DOC-005 round-trip test fails | Use `z.looseObject`/catchall everywhere, backed by a shared schema-factory helper and a lint test that scans schemas |
| `exactOptionalPropertyTypes` fights `z.infer` output | Many `as` casts in schema | Use explicit `.optional()` helpers and keep types derived; review the cast count |
| Validation too slow for 5k-record docs (it blocks the M3 undo budget) | bench `validate-5000` > 50 ms | Validate only changed records in the store (M3); keep the full validate for load |
| Floating-point drift across OSes in goldens | cross-OS snapshot diffs | Round in serialization (1e-3); compare with ε in geometry tests |

## Learned

- A step only the full ladder runs (budget) stayed red for 15 commits: read the verify leg of the m<N> gate after every commit, and record a blocker in the commit where it first appears.
