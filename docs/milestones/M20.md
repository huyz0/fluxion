# M20 — Theme studio, SVG export & DSL round-trip — **R3 exit**

| Increment | Depends on | Completion command |
|---|---|---|
| R3 | M17, M19 | `node scripts/gates/m20-complete.mjs` |

## Goal

R3 ships: a 60-node architecture diagram is auto-laid-out with no overlaps and orthogonal
connectors, themed, and exported. Themes become a studio feature — accessible palettes generated
from seed colours or an image, per-kind default styles with named variants, a live theme editor,
DTCG import/export and CSS variables. Screens export as standalone SVG that opens identically in
browsers and Inkscape. The decompiler becomes complete (raw escape blocks, idempotent), and pure
packages gain nightly mutation-score floors.

## Requirements

FR-THM-005, FR-THM-006, FR-THM-007, FR-THM-009, FR-EXP-004, FR-DSL-008, NFR-A11Y-005,
NFR-MNT-005. Completes FR-CLI-002 (`render --format svg`, from M14).

## Decide before coding

- **ADR-0055 Palette generation & DTCG mapping** — OKLCH (culori) generator from 1–3 seeds or
  image (k-means on downscaled pixels), role assignment, contrast repair loop to WCAG AA,
  lock/shuffle; DTCG ↔ theme mapping table and CSS-variable naming (`--fx-*`).
- **ADR-0056 SVG export strategy** — SSR of `<ScreenView mode="export">` to standalone SVG;
  text as `<text>/<tspan>` from measured line breaks (no `foreignObject`); fonts embedded as
  `@font-face` data URLs or outlined via fontkit; package in `<metadata>`; components via snapshot.
- **ADR-0057 Decompiler canonical form** — emission order, short names, `pin:` only for
  `placement: pinned`, `raw:` escape blocks for inexpressible records, idempotence contract.

## Scope / Non-scope

- In: `packages/theme` palette + contrast, theme `defaults[kind][variant]`, theme editor panel,
  theme files + theme packs, DTCG import/export, SVG exporter (studio + CLI), decompiler v1,
  contrast lint in validation panel, Stryker nightly floors, R3 exit checklist + demo.
- Out: light/dark theme pairs (FR-THM-010, M29); sketch/effect presets (FR-THM-011, M28);
  PDF/PNG/PPTX exporters (M30).
