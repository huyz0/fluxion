# M6 — Editor shell, canvas & selection

| Increment | Depends on | Completion command |
|---|---|---|
| R1 | M5 | `node scripts/gates/m6-complete.mjs` |

## Goal

`apps/studio` opens the editor. It has a toolbar, resizable side panels, a canvas that pans and
zooms from 5 % to 3200 %, and tools driven by a state machine. Users select (click, shift-click,
marquee), move, nudge, duplicate, resize and rotate elements with mouse, keyboard or touch. The
editor draws with the same `<ScreenView>` as present mode, which F5 switches to in place. A
parity suite proves the pixels match and a perf trace proves 500-element drags stay ≥ 55 fps.

## Requirements

FR-EDT-001, FR-EDT-002, FR-EDT-003, FR-EDT-004, FR-EDT-005, FR-EDT-009 (part: mode switch,
read-only present; animation preview/scrub in M21–M22), FR-EDT-010, FR-EDT-019, NFR-PERF-001.

## Decide before coding

- ADR-0028: editor interaction architecture. Covers hand-rolled statecharts vs XState for
  tools, the session store per document (core signals vs Zustand), the SVG overlay in screen coordinates (with the
  Canvas2D fallback criteria), and the rAF-batched pointer pipeline with `mergeKey`.
- ADR-0029: editor chrome primitives. Covers panel layout/splitters (`react-resizable-panels`
  vs Base UI + own splitter), shadcn/ui on Base UI + Tailwind v4 confined to editor chrome
  (ADR-0010), and where panel layout is persisted.

## Scope / Non-scope

- In: studio routes and bootstrap, editor layout, session store, camera, event pipeline,
  geometric hit-testing (rbush), tools framework + core tools, overlay (bounds, handles,
  marquee), selection, move/resize/rotate, touch basics, in-place present switch, parity suite,
  and the drag perf benchmark.
- Out: text editing, inspector widgets, clipboard, palette, context menus (M7); snapping, groups,
  screens panel, library (M8); save/open (M10); full player navigation (M11).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| React re-renders during drag break 55 fps | render-count test > 2 or trace shows long tasks | Transform-only wrapper writes; memo views keyed by record identity; React Compiler on |
| Parity fails on font anti-aliasing between overlay-mounted and present DOM | pixel diff 0.1–1 % | Compare with overlay slot unmounted; embed test fonts; pinned image |
| Touch gestures conflict with browser zoom/scroll on iOS | webkit mobile spec flaky | `touch-action: none` on the canvas only; recognizer thresholds in one module with T0 tests |
