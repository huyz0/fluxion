# M9 — Theme & fonts v1

| Increment | Depends on | Completion command |
|---|---|---|
| R1 | M5 | `node scripts/gates/m9-complete.mjs` |

## Goal

A document gets its look from a complete design-token theme. Eight built-in themes are
available, one-action theme switching is undoable, and per-screen overrides are possible.
Styles can reference derived tokens (OKLCH lighten/darken). Fonts come from bundled open fonts,
the Google Fonts catalog or local uploads. Document metadata is editable. Every editor string
is externalized through Lingui, and the editor UI passes axe with no serious or critical
findings.

## Requirements

FR-THM-001 (completes the M4 minimal model), FR-THM-002, FR-THM-003, FR-THM-004, FR-THM-008
(part: embedding/subsetting on save in M10), FR-DOC-006, NFR-I18N-001, NFR-A11Y-001.

## Decide before coding

- ADR-0022: font sourcing and licensing. Covers bundled OFL-1.1 fonts as *assets* (the
  licence allowlist covers code; add a separate font-licence allowlist to `check-licenses`),
  where the Google Fonts catalog snapshot comes from and how the studio fetches it (never the
  player), the local upload formats, and deferring subsetting to M10.
- ADR-0023: i18n pipeline. Covers Lingui with the Vite/Oxc toolchain (the macro is transformed
  without Babel per ADR-0008), catalog location `packages/editor/src/locales/<locale>/`, ICU
  messages, and the JSX-literal lint and its allowlist.

## Scope / Non-scope

- In: full token model, OKLCH derived tokens (culori), `packs/themes-core` (8 themes),
  theme/override commands and UI, font registry + three sources + picker, metadata schema,
  command and dialog, Lingui extraction and lint, axe/keyboard pass over the editor.
- Out: palette generator, per-kind defaults/variants, theme editor, DTCG import (M20), light/dark
  pairs (M29), extra UI locales and RTL UI (M32).
- Ordering: M9 may run in parallel with M6–M8 on its pure tasks (2–6, 8–10). The UI tasks (7,
  11–15) need the M6 editor shell merged and are ordered last.

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Lingui macro needs Babel, which the stack forbids | build fails without a Babel plugin | ADR-0023: use the SWC/Oxc-compatible transform or the non-macro `t`/`msg` API with an extractor |
| The parallel run with M6 lets UI tasks start before the shell exists | tasks 7/11–14 blocked | Order the UI tasks last; mark them `blocked` until M6 is merged instead of stubbing a shell |
| Font metrics differ between Google-served and embedded files | measurement parity drift after save (M10) | Store the exact fetched bytes as the asset; measure only from asset bytes |
