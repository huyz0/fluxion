# M30 — Exporters: PDF, PNG, PPTX, video

| Increment | Depends on | Completion command |

## Goal

A Fluxion document can leave Fluxion. Authors can export:

- vector PDFs with selectable text, one page per screen or per build step, with optional notes
  pages;
- PNG, JPEG and WebP at 1–4× with optional transparency (PNG can carry the editable document);
- PPTX with native, editable shapes, connectors, text and notes;
- MP4, WebM or GIF recordings of animated screens.

Each export runs from the studio dialog or `fluxion export`. It uses the same renderer as present
mode, so the output matches what the viewer sees.

## Decide before coding

- **ADR-0122 Export runtime.**
  - The player's `export` mode shows the final-build state or a given step, runs on the virtual
    clock, waits for `document.fonts.ready`, and uses component snapshots.
  - The CLI drives Playwright Chromium as an optional peer dependency, with a clear message and an
    install hint when it is missing.
  - The studio uses in-browser paths where possible.
- **ADR-0123 PPTX mapping.**
  - Use **pptxgenjs** (MIT). Verify that the MIT side of jszip's MIT/GPL dual licence is recorded
    in `check-licenses`.
  - Map the shape-def table to preset geometry; everything else becomes custom geometry.
  - Connectors export unbound, and animations are not mapped.
  - "Builds as slides" is an option.
- **ADR-0124 Video pipeline.**
  - The default is Playwright `recordVideo` (WebM).
  - A deterministic mode steps the VirtualClock and captures frames.
  - Frames are encoded by a **system** ffmpeg (not bundled, for licence reasons), and GIF uses
    **gifenc** (MIT).
- Reference: 10 §6, ADR-0006 (sample(model, t) makes frame capture exact).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Chromium print differs from screen render (filters, blend modes, fonts) | PDF diff > 1 % on effect fixtures | Rasterise unsupported effects into images in export mode; per-effect print fallbacks |
| Playwright browser download in user environments | CLI export fails on fresh machines | Optional peer + actionable error; `fluxion doctor` check; studio path as alternative |
| PPTX fidelity disputes (custom geometry, text metrics) | LibreOffice render diverges heavily | Keep editable text, accept geometric approximation; image fallback per element option |
