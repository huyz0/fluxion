# M19 — Advanced editing: containers, layers, paths, tables, masters

| Increment | Depends on | Completion command |
|---|---|---|
| R3 | M18 | `node scripts/gates/m19-complete.mjs` |

## Goal

The editor handles structured, production diagrams. Frames/containers clip and carry their
children; a layers panel shows the element tree with visibility, lock and drag-reorder; shapes
can have multiple text regions and icon slots, locks and flips; vector shapes support boolean
operations and vertex/bezier editing; tables are a native shape; master screens provide shared
backgrounds, placeholders and elements. Quick-connect handles and element search speed up
everyday diagramming.

## Requirements

FR-ARR-006, FR-ARR-007, FR-ARR-008, FR-SHP-007, FR-SHP-008, FR-SHP-009, FR-SHP-010,
FR-SHP-011, FR-SHP-014, FR-SCR-005, FR-EDT-015, FR-EDT-016.

## Decide before coding

- **ADR-0052 Frames & containment semantics** — `frame` record behaviour (clip, padding,
  child reparenting on drop, transform inheritance, interaction with live layouts from M17 and
  with groups), hit-testing inside clipped frames.
- **ADR-0053 Boolean path operations** — `polygon-clipping` (MIT) on adaptively flattened
  cubics with curve re-fit vs. `paper.js` path booleans (MIT, lazy chunk); precision targets;
  runs in `geometry` (pure) or a lazy editor chunk.
- **ADR-0054 Masters and tables in the schema** — `screen.masterId`, placeholder mechanism and
  override precedence; `table` element (`rows`, `cols`, `cells`, merges, theme table styles);
  additive schema minor + migration fixture.

## Scope / Non-scope

- In: frames, match size / format painter, layers panel, text regions & icon slots, locks,
  flips (geometry + anchors), boolean ops, path editing tool, table shape + editing, master
  screens + editor, quick-connect, element search.
- Out: sub-screens / drill-down (M25); component shapes (M27); responsive overrides (M29);
  comments (M32).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Boolean ops on flattened curves produce jagged or huge paths | golden point count explodes; visual steps | Adaptive flattening + curve re-fit; tolerance in ADR-0053 |
| Frame vs group vs live-layout semantics tangle | conflicting reparent/undo bugs in E2E | One containment model in ADR-0052; property test on reparent + undo |
| Master inheritance breaks parity or export | parity diff > 0.1 % on master fixture | Masters rendered in background layer by the same `ScreenView` path in all modes |
