| Increment | Depends on | Completion command |

## Goal

Presentations tell a story over time. Each screen has a reversible build sequence with click,
with/after-previous, event, enter and time triggers; deep links land on the exact cumulative
state without replaying. Screens change with classic transitions or **magic move**, where
matched elements tween position, size, style and geometry (morphing between different outlines)
and connector routes morph. Layout changes animate in both modes, kiosk decks auto-advance, the
editor has a timeline panel, and FluxScript expresses steps and transitions.

## Decide before coding

- **ADR-0061 Build semantics** — click groups, trigger kinds, `endStates` precomputation,
  `next`/`prev` rules incl. `onEvent`/`onTime` gates, finishing a running group on new input,
  named timelines with own clocks.
- **ADR-0062 Transitions & magic move** — TransitionManager (current/incoming/preloaded),
  `matchKey` rule (`screen.duplicate` sets it), model-geometry from/to, morph path selection
  (same-structure lerp fast path vs. `flubber`, `maxSegmentLength` per tier), text cross-fade,
  View Transitions API as optional enhancement only.
- **ADR-0063 Layout & route animation** — layout diff → FLIP tween of model boxes, route morph
  with `d3-interpolate-path` and endpoints pinned to animated anchors, fade in/out of added/
  removed nodes, commit at t = 1 as one transaction.

## Scope / Non-scope

- In: `anim` build reducer + morph + route morph, player controller/transition manager,
  kiosk mode, deep links to steps, timeline panel, layout animation (edit + present), DSL
  `steps:`/`transition:`, lazy morph chunk.
- Out: riders, connector flows, text animations, Lottie (M23); interaction-driven navigation
  and per-link transitions (M24); zoom-into sub-screen transition (FR-TRN-003, M25).

| Risk | Signal | Mitigation |

| Magic move with connectors produces detached lines mid-tween | route-morph property fails | Re-route from interpolated anchors each frame; snap to final route at t = 1 |
