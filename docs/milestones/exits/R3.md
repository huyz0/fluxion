# R3 exit checklist

The exit criteria of increment R3, the designer's toolbox (`docs/requirements/01-scope-and-increments.md` §2, and R3's demo: `examples/r3-architecture.flux.html`, 60 nodes, orthogonal, no overlap).
R3 spans M16 to M20 and the roadmap puts its exit at M20. This file starts at M16, which closes the anchors and routing part; M17 to M20 add their rows, and M20's gate adds the increment-wide `check-trace --increment R3`.
Each line says how it is checked; a box is ticked only when that check passes today. `m16-complete` fails while one of rows 1-11 has no evidence link that resolves or a box still open; ticking a box once its evidence arrives does not move the final review range (`AFTER_REVIEW_PATHS`).
