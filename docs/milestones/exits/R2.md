# R2 exit checklist

The exit criteria of increment R2, AI authoring and MCP (`docs/requirements/01-scope-and-increments.md` §2, and R2's demo: *an agent builds a deck over MCP and the file renders*).
Each line says how it is checked; a box is ticked only when that check passes today. `m15-complete` fails while a row has no evidence link.
