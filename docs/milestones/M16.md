# M16 — Anchors & smart routing

| Increment | Depends on | Completion command |

## Goal

Connectors look hand-drawn by a careful designer. The own orthogonal router (A* on a sparse
grid + nudging + simplification) avoids obstacles with minimal bends, anchors come in
fixed/side/perimeter/center kinds with roles and limits, `auto` anchors pick the best side after
layout, multiple connectors spread along a side, parallel connectors fan out, crossings get line
jumps, and connectors can attach to other connectors. Dragging a shape re-routes only affected
connectors at frame rate; a worker pass polishes on drop. Large screens (2k elements + 1k
connectors) stay fluid.

## Decide before coding

- **ADR-0042 Orthogonal router** — sparse non-uniform grid (obstacle edges ± margin, anchor
  stubs, midlines), A* cost `length + bend·B + crossing·C`, nudge/simplify post-passes; own
  implementation is the default, `routing-libavoid` stays an optional later pack (LGPL boundary).
- **ADR-0043 Anchor model & auto-selection** — anchor kinds schema (minor bump), scoring weights
  from architecture 05 §8 as tunable router options, hysteresis H ≈ 15 %, `maxConnections` spill.
- **ADR-0044 Incremental and global routing** — bindings index for affected-only reroute during
  drag, cheap pass (no nudge/labels) per frame, worker global pass on drop, route cache keyed by
  fingerprint.

## Scope / Non-scope

- In: `packages/routing` (anchors, orthogonal, nudge, simplify, labels, fan-out), geometry
  sweep-line for jumps, connector-to-connector bindings, editor anchor UX, culling/flatbush for
  big screens, benches and perf traces.
- Out: custom pack connector types (M18, FR-CON-010); libavoid/ELK packs (optional, not
  required by any M requirement — record in roadmap "Deferred" if pursued); route morph (M22);

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| A* on dense screens too slow for 200-route budget | bench > 300 ms | One grid per batch, shared index, bounded search window; worker for > 50 connectors |
| Auto-anchor flicker during drag | E2E video shows side jumps | Hysteresis term; freeze choice during drag, re-score on drop |
| Nudging breaks obstacle avoidance | property test finds segment inside obstacle after nudge | Nudge within channel bounds only; re-check and fall back to un-nudged route |
