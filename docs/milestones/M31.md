## Goal

`fluxion site build deck.flux -o dist/` turns a document into a deployable static site. Each
section or screen becomes a page, with navigation, deep links, client-side search, SEO and
OpenGraph metadata, and page content that reads with JavaScript disabled. Hydration then adds
motion and interactions. A single-file variant works offline. Authors can also bring content in
from PowerPoint, draw.io, Excalidraw, D2 and Graphviz. R7 closes with `examples/r7-site/`, built
from the same document that presents as the desktop deck and reflows on a portrait phone.

## Decide before coding

- **ADR-0125 Site generation pipeline.**
  - A Node `TextMeasurer` uses the embedded fonts.
  - Pages are prerendered with React 19 `react-dom/static` in the final-build state.
  - Each page gets a JSON records file, and one shared hashed player chunk hydrates with
    `hydrateRoot`.
  - Route and slug rules, and URL stability when screens are renamed.
- **ADR-0126 Site search.** Compare **Pagefind** (MIT; build-time chunked index, fetched at
  runtime) with **MiniSearch** (MIT; lazy JSON index, works inside the single-file variant and
  from `file://`). The expected choice is MiniSearch for both variants, with Pagefind considered
  only if the index for a large site exceeds its budget. The ADR records the index size budget.
- **ADR-0127 Importer mapping and fidelity.**
  - Mapping tables for PPTX DrawingML, draw.io style strings and Excalidraw elements.
  - Semantic sources (D2, DOT) emit FluxScript. Geometric sources emit pinned records.
  - DOT parsing uses `ts-graphviz` (MIT, verify licence). D2 gets a subset parser.
  - The XML parser has DTDs and entities disabled.
- Reference: 10 §5 and §7, ADR-0003 (single-file shell), ADR-0004 (FluxScript).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Node text measurement differs from browser → prerender/hydration mismatch | Hydration warnings, text overflow in SSR pages | Same embedded fonts + fontkit metrics; TXT-002 parity test in Node vs browser |
| Search index too large for big docs in single-file variant | Index > budget | Field weighting + stopwords; per-section lazy indexes; ADR-0126 fallback |
| PPTX real-world decks (SmartArt, groups, placeholders) under 80 % | Coverage metric below target | Image fallback counts as imported only for charts/SmartArt; broaden fixture set early |
