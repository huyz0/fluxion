## Goal

Connectors move in present mode. Riders (dots, electrons, packets, icons) travel along live
routes and stay on them when a route changes, at 500 riders on desktop and 200 on mobile. Flow
effects (draw-on, marching ants, pulse, glow, colour sweep, comet) and gradient strokes show
direction and intensity. Text can animate (typewriter, per-word or per-letter reveal, count-up)
and can contain fields. Lottie/dotLottie, Rive, video and audio assets play when a trigger tells
them to. The AI toolkit gains generation modes such as "animate this screen" and "explain as
build steps". R4 closes with `examples/r4-power-grid.flux.html`.

## Decide before coding

- **ADR-0100 Rider rendering backends.** Riders use DOM `offset-path` up to N per screen
  (starting value 50), a canvas layer above N, and an OffscreenCanvas worker where the browser
  supports it. The ADR records the measured crossover N, how tiers fall back, and how the worker
  loads under the `.flux.html` CSP (Blob URL).
- **ADR-0101 Rich-media packs.** `packs/media-lottie` uses `@lottiefiles/dotlottie-web` (MIT,
  ThorVG WASM) and `packs/media-rive` uses `@rive-app/canvas` (MIT). Both are optional and lazy,
  and their WASM is inlined as base64 only in files that use them. Video and audio are a core
  `media` element kind. The ADR sets size budgets and confirms the licence gate passes.
- **ADR-0102 Flow and along-path gradient rendering.** Choose between segmented SVG strokes
  sliced from the rider LUT and a mask-based approach. The choice must keep SVG goldens
  deterministic and SVG export faithful (FR-EXP-004).
- Reference: ADR-0006 (`sample(model, t)`), ADR-0003 (assets), ADR-0007 (packs through the SDK).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Canvas riders look different from DOM riders at the backend crossover | T3 diff between 49- and 51-rider fixtures | One shared style→draw mapping; golden at both sides of the threshold |
| OffscreenCanvas worker blocked (CSP, `file://`, Safari) | webkit T2 failure | Main-thread canvas fallback selected at runtime; tested explicitly |
| Lottie/Rive WASM bloats saved files | NFR-SIZE-003 fixture growth | Embed WASM only when a media element uses it; `lottie-web` light SVG player as fallback option in ADR-0101 |
| Mode evals noisy with recorded responses | Scorecard swings between runs | Fixed recordings in CI; live nightly only, threshold on 3-run median |
