## Goal

A presented document responds to its viewer. Declarative rules (`trigger → [condition] →
actions[]`) react to clicks, hovers, keys, timers, variable changes and rider arrivals. They can
navigate non-linearly with a back stack, open popups (anchored, modal, drawer, full-screen),
show or hide elements, and play timelines or set typed document variables. Variables drive text
fields and flow intensities. Everything works from the keyboard and is announced to screen
readers. The same rules can be written in FluxScript (`on click a: popup detail-a`).

## Decide before coding

- **ADR-0103 Interaction engine semantics.** Covers:
  - rule evaluation order;
  - a serial action queue with cascade depth ≤ 32;
  - `once` rules;
  - re-entrancy while a transition runs;
  - how rule actions interleave with build navigation (`next` during an open modal).
- **ADR-0104 Overlay primitives.** Modals use `<dialog>.showModal()` and non-modal/anchored
  overlays use the `popover` attribute, both inside the player's shadow DOM. Anchored overlays
  are positioned from the model box (CSS anchor positioning only as an enhancement). The ADR
  also covers stacking with several overlays.
- **ADR-0105 Variable scope.** Variables are session-scoped. They are not in the URL (07 §4.5)
  and are reset on reload. The ADR fixes typed coercion rules, and records that the `color`
  type goes through the theme token resolver.
- Reference: ADR-0006 (every visual state = `sample`), 07 §3.5 expression grammar.

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| `popover`/`<dialog>` behave differently inside shadow DOM across engines | webkit/firefox overlay E2E fails | ADR-0104 fallback: manual focus trap + `inert` polyfill path, tested per engine |
| Rule cascades or timer rules make navigation nondeterministic | Flaky branching E2E | Serial queue + virtual clock in tests; cascade depth cap; ADR-0103 ordering rule |
| Hover-centric authoring breaks touch and keyboard | Lint warnings on examples | Lint "hover-only rule" + automatic focus/long-press equivalents |
