# M1 — Monorepo & toolchain skeleton

| Increment | Depends on | Completion command |
|---|---|---|
| R0 | M0 | `node scripts/gates/m1-complete.mjs` |

## Goal

A fresh clone becomes a working TypeScript monorepo with `pnpm i && pnpm setup && pnpm verify`.
Every package in the architecture map exists as an empty, documented stub. The layering,
licence, trace, API, size and coverage gates are wired into `pnpm verify` and CI, and each gate
has a negative fixture proving it fails. After M1, product code (M2+) lands in a repo where any
rule an agent breaks goes red before it can commit.

## Requirements

NFR-MNT-001, NFR-MNT-002, NFR-MNT-003, NFR-MNT-004, NFR-MNT-007 (part: gate and reports now;
freeze in M33), NFR-PORT-005, NFR-DX-001, NFR-DX-002, NFR-SEC-005, NFR-LIC-001, NFR-LIC-002,
NFR-MNT-008 (part: `check-trace.mjs` completes the M0 groundwork), NFR-DX-004 (part: retry policy).

## Decide before coding

- ADR-0008 toolchain is the reference. If only the index row exists and there is no file under
  `docs/architecture/decisions/`, write the file first from `tech-stack.md`.
- ADR-0011: workspace source resolution and dual compiler. Covers the `@fluxion/source` export
  condition vs build-first, and `tsgo -b` (TS 7) for typecheck with TS 6 for API Extractor and
  TypeDoc.

## Scope / Non-scope

- In: root config, catalogs, Turborepo pipelines, strict tsconfig, stubs for all packages
  (`schema`, `geometry`, `core`, `theme`, `layout`, `routing`, `anim`, `format`, `dsl`, `render`,
  `player`, `editor`, `sdk`, `cli`, `mcp`, `exporters`), `apps/studio`, `apps/docs`,
  `packs/basic`, gates, test runners, Storybook, CI, security workflows, Renovate.
- Out: any product behaviour. Stubs export a single `VERSION` constant. No real E2E journeys.

## Completion gate legs

- `pnpm verify` exits 0 on a clean checkout.
- `node --test "tests/harness/*.test.mjs"` passes, with a negative test for each new gate: layering, size, licenses, trace, api, budget, tsconfig strictness, Biome rules.
- `check-trace.mjs --milestone M1` is green.
- All 16 packages, both apps and `packs/basic` exist with `index.ts`, `README.md`, `AGENTS.md` and `LICENSE`.
- `turbo run build` reruns as a full cache hit.
- Playwright lists 5 projects and the chromium smoke spec passes. The Storybook test passes. The docs site builds.
- `ci.yml`, `security.yml`, `nightly.yml`, `release.yml` and `renovate.json` exist, and actionlint and zizmor are clean.
- `check-budget` is within the `QUICK_GATE_BUDGET_MS` and `PRECOMMIT_BUDGET_MS` limits in `thresholds.mjs`.
- The milestone-review verdict is recorded and there are no open quarantines.

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| TS 7 (`tsgo`) and API Extractor/TypeDoc disagree on `.d.ts` | `check-api` fails on generated declarations | Keep TS 6 for API tooling (ADR-0011); `isolatedDeclarations` keeps the d.ts input simple |
| Pre-commit budget blown by Playwright/Storybook | `check-budget` > 120 s | Browser tiers run in CI only; pre-commit runs T0 + related T1 |
| Windows path/shell differences in gates | `verify` red only on windows runner | Node-only scripts, `path.posix` for globs, windows leg in CI from task 18 |
| Biome lacks a rule (e.g. complexity, restricted globals per folder) | rule cannot be expressed | Enforce in `check-size`/`check-layering` instead and note it in the standard |
