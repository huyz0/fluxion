## Goal

Every common diagram family lays itself out. `@fluxion/layout` adds `tree`/`orgchart`,
`radial`, `mindmap`, `force`, `circular`, `packing`, `timeline` and `swimlane`; layouts honour
pins and relative constraints and can run incrementally without destroying the mental map.
Frames can carry a **live layout** that re-runs on content change, "Tidy up" cleans a messy
screen with minimal movement, "Fit to screen" keeps content in the safe area, and SmartArt-like
templates (process, cycle, hierarchy, pyramid, matrix, venn, funnel, timeline, comparison) are
selectable by name from DSL, AI patches and the editor.

## Requirements

FR-LAY-003, FR-LAY-006, FR-LAY-010, FR-LAY-011, FR-LAY-012, FR-LAY-014.

## Decide before coding

- **ADR-0045 Layout suite v2 backing libraries** — `d3-hierarchy` + `d3-flextree` (tree,
  orgchart, radial, mindmap), `d3-force` with `randomSource(rng)` + rect collide, WebCola for
  constraints/tidy, own circular/packing/timeline/swimlane; optional `packs/layouts-elk` (elkjs,
  EPL-2.0, unmodified, lazy worker chunk, notices) per NFR-LIC-002.
- **ADR-0046 Live containers & incremental mode** — post-commit reactor, one run per frame,
  `mergeKey` so edit + re-layout undo as one step; displacement-minimizing reconciliation for
  algorithms without native warm start; ≤ 30 % moved metric definition.
- **ADR-0047 Smart template format** — `TemplateDef` (items schema, `build`, slots → shapes and
  theme variants, `adapt` for portrait), DSL syntax `template: process.chevron` + `items:`.

## Scope / Non-scope

- In: 8 algorithms + fixtures, `constraints` post-pass, incremental mode, live frames, `tidy`,
  `fit`, templates registry + 9 templates, DSL/catalog/patch exposure, editor layout picker with
  generated options, optional ELK pack.
- Out: responsive re-layout per breakpoint (FR-LAY-013, M29); layout animation (FR-LAY-009, M22);
  Cassowary constraints (`@lume/kiwi`, reserved).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Force layout non-deterministic across platforms (float order) | determinism test fails on one OS leg | Fixed iterations, sorted inputs, 0.5 px quantization, CI OS matrix run |
| Live containers cause re-layout storms / undo splits | E2E shows two undo entries or stutter | Per-frame debounce, `mergeKey`, reactor ignores its own commits |
| Template geometry breaks with long labels | text overflow lint on template goldens | Measure text before build; templates grow slots, then fit |
