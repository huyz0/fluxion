| Increment | Depends on | Completion command |

## Goal

An external agent can drive Fluxion entirely from a shell. `fluxion` gains `compile`,
`decompile`, `validate`, `lint`, `layout`, `render`, `catalog`, `migrate`, `convert`, `patch` with a
stable `--json` envelope and exit codes. Agents get a generated JSON Schema for documents and
AI patches, a token-efficient catalog (≤ 8k tokens with the authoring guide), atomic patch
operations addressed by slug, LLM-ranked diagnostics with fix hints, a quality linter with a
score, PNG render for visual self-check, and `llms.txt`. This is the operation layer the MCP
server (M15) wraps one-to-one.

after-repair eval lands in M15), FR-AI-005, FR-EDT-021 (part: the Problems tab lists lint findings, handed off from M7), FR-AI-006, FR-AI-011 (part — MCP resource embedding

FR-EXP-007, FR-EXP-008, NFR-AI-002, NFR-AI-003.

## Decide before coding

- **ADR-0035 AI patch format v1** — ops from architecture 06 §5, `Ref` grammar (slug, `#id`,
  edge key), atomicity, `baseRevision` staleness, provider-strict JSON Schema subset
  (`additionalProperties:false`, flat unions).
- **ADR-0036 CLI contract** — `CliResult<T>` envelope, stdout/stderr split, exit codes 0/1/2/3,
  `@fluxion/cli/ops` as the single operation layer; Playwright Chromium as an optional peer for
  `render --png` (clear usage error when absent).
- **ADR-0037 Fixed tokenizer for budgets** — one pinned offline tokenizer (e.g. `gpt-tokenizer`
  o200k, MIT) as proxy for NFR-AI-002/003 counts; documented error margin vs. reference model.

## Scope / Non-scope

- In: `specs/schema/*.json` generation, `buildCatalog`, `describe` enforcement in registries,
  `packages/dsl/src/patch/`, `ai.applyPatch` command, diagnostic formatter, `lintRules`
  registry + core rules, `packages/cli` commands and `ops`, Mermaid exporter, decompile/JSON
  export, `apps/docs` llms.txt, token-budget tests.
- Out: MCP server, generation orchestrator, eval suite, provider adapters (M15); SVG/PDF render
  (M20/M30); full decompiler (M20).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Catalog exceeds 8k tokens as packs grow | token-budget test near limit | Summary lines only by default; `--detail=<pack>` for expansion; budget test per pack |
| Strict JSON Schema subset cannot express Zod unions | provider structured-output rejects schema | Flatten unions in a dedicated `patch-strict` emitter; test against a fixture of provider rules |
| Headless Chromium install on Windows/CI flaky | render e2e fails intermittently | Optional peer + pinned Playwright image; quarantine rule applies, not retries |
