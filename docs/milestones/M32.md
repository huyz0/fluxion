## Goal

Fluxion is ready to be trusted by strangers. Document text in any script (RTL, CJK, emoji) renders,
edits, measures and exports correctly. The editor ships in English, Vietnamese and Spanish with
an RTL-capable UI. Authors get comments, a version history with visual diff, and
password-protected export. Every NFR in `30-non-functional.md` is re-measured on the reference
setup and recorded with evidence. That includes:

- a full accessibility audit with screen readers;
- a cross-OS render determinism job;
- a performance pass that includes editor memory;
- a security review against a written threat model.

## Decide before coding

- **ADR-0128 Text shaping, bidi and hyphenation.**
  - Browser shaping is used in DOM.
  - fontkit/HarfBuzz (hb wasm) shapes text for SVG/PDF outlines and the Node measurer.
  - `lang` can be set per document or element.
  - Hyphenation uses CSS `hyphens` in the browser and a matching Node dictionary.
  - Noto fallback subsets are chosen by the scripts the document uses.
- **ADR-0129 Encrypted export.** AES-GCM-256 through WebCrypto. The key comes from Argon2id
  (`hash-wasm`, MIT), with PBKDF2-SHA256 at ≥ 600k iterations as a fallback. The encrypted
  payload is `encrypted.bin` inside the standard HTML shell (08 §10). A password prompt unlocks
  it, and a lost password cannot be recovered.
- **ADR-0130 Comments and version history.** `comment` records live in the file but are excluded
  from present mode, export and site output. Autosave snapshots (last N) are kept in IndexedDB,
  and visual diffs are computed from the rendered SVGs of the two versions.
- **ADR-0131 Threat model (STRIDE).** Covers opening a file, the plugin sandbox, embeds, the MCP
  live link, the remote-control relay, AI provider keys, the site build and importers. Each
  threat maps to a test or a corpus entry.
- **ADR-0132 UI i18n and RTL.** Lingui catalogs for `en`, `vi` and `es`. The UI uses logical CSS
  properties only, and an `en-XA-rtl` pseudo-locale is used for RTL visual tests.

## Scope / Non-scope

- In:
  - Unicode text end-to-end.
  - UI locales and RTL.
  - Comments, history and encryption.
  - All NFR audits and fixes.
  - The cross-OS nightly job.
  - An NFR audit report.
- Out:
  - More locales beyond the three.
  - Real-time collaboration.
  - Cloud key escrow.
  - A formal third-party penetration test (recommended after 1.0).

|---|---|---|
