# M21 — Animation runtime & effects

| Increment | Depends on | Completion command |
|---|---|---|
| R4 | M20 | `node scripts/gates/m21-complete.mjs` |

## Goal

Elements move. `@fluxion/anim` evaluates a declarative, serializable animation model as a pure
`sample(model, t)`; the player drives it with one clock, a rAF sampler and paused WAAPI
animations for compositor properties. Entrance, exit and emphasis effects, motion paths and
property keyframes ship in `packs/effects-core`. Ambient loops run only while visible, reduced
motion is honoured, flashes are linted, and authors preview animations in the editor on a
controlled clock with the final state shown by default.

## Decide before coding

- **ADR-0058 Animation schema v1 & effect registry** — `timeline`/`step` records and
  `Animation`/`Track`/`Keyframe`/`Easing` shapes (07 §2) as a schema minor; `EffectDef`
  contract (`params` Zod, `compile → Track[]`, `reduced()`, `maxFlashHz`); preset ids.
- **ADR-0059 Player scheduler** — `Clock` port (realtime / controlled / virtual), single rAF
  loop, WAAPI for transform/opacity with baked `linear()` easing, rAF sampler for SVG attrs,
  `ElementHandle` writes, performance tiers and their triggers.
- **ADR-0060 Motion policy** — `respect | reduce | full` document setting + player toggle;
  reduced variants (fades ≤ 200 ms), `essential` handling, flash limit ≤ 3 Hz, pause control for
  motion > 5 s.
- References ADR-0006 (own animation model).

## Scope / Non-scope

- In: `packages/anim` (pure: compile, sample, interpolation, OKLCH colours, easing, LUTs for
  motion paths), `packages/player` scheduler + drivers, `packs/effects-core` presets, ambient
  loops, visibility pause, motion policy, flash lint, perf tiers, edit-mode preview.
- Out: build sequences / click groups / triggers (M22), transitions & morph (M22), riders and
  connector flows (M23), text animations and Lottie (M23), interactions (M24).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| WAAPI and rAF sampler drift apart | T1 seek comparison differs by > 1 px | WAAPI always paused and seeked from scheduler time; rAF is the source of truth |
| Player bundle creeps over 150 kB | size-limit delta per PR | Effects compile in lazy `anim` chunk; presets are data |
| Safari WAAPI/`linear()` gaps | webkit E2E fails | Feature-detect; fall back to rAF sampler for easing |
