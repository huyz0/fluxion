# M10 — File format & persistence

| Increment | Depends on | Completion command |
|---|---|---|
| R1 | M8, M9 | `node scripts/gates/m10-complete.mjs` |

## Goal

A deck saves as one self-contained `.flux.html` that presents offline from `file://` under a
strict CSP. It also saves as a compact, deterministic `.flux` zip, and the two convert
losslessly. Opening accepts a picker, drag-drop, `?src=` or paste. The loader never throws: it
migrates, repairs and salvages. Autosave protects work within 5 s and offers recovery after a
crash. Assets are sniffed, optimized, sanitized, content-addressed and embedded only when used,
which keeps a 20-screen deck within the size budgets.

## Decide before coding

- ADR-0003 (file format) is the reference. If only the index row exists, write the file first
  from `08-file-format.md`.
- ADR-0024: autosave storage. Covers the IndexedDB journal schema (raw API vs `idb`), OPFS for
  asset bytes and version snapshots, quota and eviction handling, and multi-tab locking (Web
  Locks).
- ADR-0025: sanitizer and image encoding. Covers an own allowlist SVG sanitizer over a portable
  XML parser (identical in Node and the browser) vs DOMPurify + a DOM shim, and WebP/AVIF
  encoding (`OffscreenCanvas` in the browser, a wasm encoder in the CLI).

## Scope / Non-scope

- In: `@fluxion/format` writer/reader for `.flux` and `.flux.html`, manifest and hashes, asset
  store, loader pipeline, sanitizers + security corpus, a minimal inline player build (static
  screens, arrow navigation) for the HTML shell, CSP, image and font embedding, asset manager,
  studio open/save/autosave/recovery/recents, `fluxion convert`, size fixtures, format fixtures.
- Out: `.flux.json` pretty variant (M12), external asset URLs (M15), plugin bundles and
  integrity (M27), encryption (M32), full player features (M11).

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Inline module scripts from `file://` behave differently per browser (Safari opaque origin) | webkit offline spec fails | Keep an inline classic-script fallback; test `file://` on all three engines from task 11 |
| `.flux.html` over 450 kB due to the player bundle | size fixture red at task 18 | Measure at task 7; lazy-split non-essential code; enable compact mode only after the spike in `08-file-format.md` |
| OPFS/IndexedDB quota or private-mode restrictions | autosave errors in Firefox private/Safari | Detect and surface "autosave unavailable"; fall back to in-memory journal plus save prompt |
| Sanitizer differences between Node and browser | CLI vs studio corpus outputs differ | One sanitizer over a portable XML parser (ADR-0025); corpus runs in both |
