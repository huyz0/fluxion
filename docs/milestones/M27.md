# M27 — Component elements, packaging & sandbox

| Increment | Depends on | Completion command |
|---|---|---|
| R6 | M26 | `node scripts/gates/m27-complete.mjs` |

## Goal

A plugin can register a React component as an element kind. The component can act as a shape,
connector label, rider or popup content. It emits events that trigger interactions, exposes
methods that actions can call, and declares anchors that change at runtime. It renders only from
its props and the host clock. Plugins ship as `.fluxpack` files with integrity hashes. Saving a
document embeds only the player code of the plugins it actually uses, and that code shares the
host's React through an import map. Code of unknown origin runs in a sandboxed iframe. A
crashing or missing plugin degrades to a snapshot or placeholder and never loses data or
white-screens the editor.

## Decide before coding

- **ADR-0113 Sandbox runtime.**
  - `sandbox="allow-scripts"` `srcdoc` iframes with an opaque origin.
  - A strict CSP.
  - MessageChannel RPC with Zod-validated messages (09 §8).
  - Iframe pooling per visible instance, and camera sync.
  - A snapshot while an instance is offscreen.
  - Behaviour under `file://`.
- **ADR-0114 `.fluxpack` and file-level integrity.**
  - Zip layout (`mimetype` first, stored).
  - The `integrity.json` format.
  - The payload hash in `manifest.json`.
  - A signature slot whose key format M33 reuses (FR-PKG-005).
- **ADR-0115 Shared dependencies in `.flux.html`.** An import map with shim modules, and a
  fallback that rewrites bare specifiers with es-module-lexer. The ADR records the result of the
  research 04 §D.9 spike on chromium, firefox and webkit.
- Reference: ADR-0007 (trust model), ADR-0003 (container), 09 §6–9.

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| Import maps can't be installed after boot / under CSP in some engines | ADR-0115 spike fails on webkit | Specifier-rewrite fallback is the default path in `.flux.html` |
| Iframe-per-instance sandbox too slow for many components | Frame drops with > 20 sandboxed instances | Pool + snapshot offscreen; cap live iframes per screen; document limit |
| Snapshot rasterisation differs from live render | Export diff > 1 % | Prefer component `snapshot()` SVG; rasterise via same renderer at DPR 2 |
