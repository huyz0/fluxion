# M12 — FluxScript DSL compiler

| Increment | Depends on | Completion command |
|---|---|---|
| R2 | M11 | `node scripts/gates/m12-complete.mjs` |

## Goal

An author (human or model) writes `*.flux.yaml` FluxScript and gets a canonical Fluxion
document: `@fluxion/dsl` parses with source ranges, resolves slugs/shapes/tokens against the
registries, expands groups, applies theme variants, places unpinned elements, validates, and
reports diagnostics with line/col and a did-you-mean fix. The studio gains a **Source view**
that edits the current screen as FluxScript with two-way sync, and screens stream in one by one
as a partial file arrives. `.flux.json` becomes byte-deterministic so compiled output diffs
cleanly in git.

## Requirements

FR-DSL-001, FR-DSL-002, FR-DSL-005 (part — pins + simple fallback placement; auto layout via
`layered` lands in M13), FR-DSL-006, FR-DSL-009, FR-FIL-005, FR-EDT-022, FR-AI-010.
Enables later: FR-DSL-003/004 (M22/M24 extend grammar), FR-DSL-008 (full decompiler, M20).

## Decide before coding

- **ADR-0030 FluxScript grammar v1 freeze** — top-level shape, slug rule, edge shorthand ops
  (`-> <- <-> -- ~>`), anchor suffix, which sections compile in R2 vs. are parsed-and-deferred
  (`steps`, `interactions`, `riders`, `flow` → `FLX_DSL_NOT_YET` warning, preserved in
  `document.source`), and the diagnostic-code registry (`packages/dsl/src/diagnostics/codes.ts`).
- **ADR-0031 Stable IDs and placement** — `id = base62(hash128(docSalt + ':' + slug))` via the
  `Hasher` port; additive schema minor adding `screen.layout?` and `element.placement?`
  (`auto | pinned`) with migration + fixture (contracts.md).
- **ADR-0032 Source-view editor** — CodeMirror 6 (MIT, lazy chunk, editor only) with a Lezer
  grammar generated alongside a TextMate grammar; sync strategy (screen-scoped recompile,
  source-map driven selection, debounce 300 ms, one undo transaction per applied recompile).
- References ADR-0004 (FluxScript DSL), ADR-0003 (file format).

## Scope / Non-scope

- In: `packages/dsl` (parse → resolve → expand → style → place → validate), diagnostics with
  hints, a screen-level decompiler **v0** (needed for DSL→doc→DSL and Source view), streaming
  block splitter, `.flux.json` deterministic writer in `packages/format`, TextMate + Lezer
  grammars, CodeMirror completion, Source view panel, `examples/dsl/*.flux.yaml`.
- Out: layout algorithms (M13), lint rules (M14), patches/catalog CLI (M14), Mermaid/Markdown
  importers (M15), animation/interaction grammar compile (M22/M24), full decompiler with raw
  escape blocks (M20).

## Completion gate legs

- `check-trace --milestone M12`: every Req ID above has ≥ 1 passing test titled with it.
- Every file in `examples/dsl/` compiles with 0 errors; `checkout.flux.yaml` yields only
  `FLX_DSL_NOT_YET` warnings.
- Determinism: compile each example twice → identical SHA-256 of `.flux.json`.
- Round-trip property test (`roundtrip.prop.test.ts`) passes at the CI seed.
- Playwright specs `source-view.two-way-sync.spec.ts` and `dsl.streaming-render.spec.ts` pass
  (chromium, firefox, webkit).
- Schema v1.1 fixture present and migration test green.
- size-limit: editor initial ≤ `EDITOR_INITIAL_GZIP`, player core ≤ `PLAYER_CORE_GZIP` (dsl
  not in player).
- Coverage floor for `packages/dsl` ≥ 90 % lines / 85 % branches.
- No open quarantines or spec folders for M12; milestone-review verdict `pass` recorded.

## Risks

| Risk | Signal | Mitigation |
|---|---|---|
| `yaml` CST ranges lost through our transforms → wrong line/col | diagnostic snapshots point to wrong lines | Keep ranges on every intermediate node; test col for each code |
| Two-way sync loops or clobbers user text | cursor jumps / duplicate undo entries in E2E | Screen-scoped recompile, source-map diffing, suppress regeneration while editor focused |
| Grammar churn after freeze breaks AI prompts | ADR amendments pile up | Additive-only rule in ADR-0030; new sections gated by `flux:` version |

## Learned

- cp1: the rule that a row adds its test titles to the gate leg was followed only by M12.16; a row's commit edits `m12-complete.mjs` or says why not (cp1 F1).
- cp1: `check-trace --milestone` checks Must requirements only; a plan whose requirements are Should (FR-DSL-009, FR-EDT-022, FR-AI-010) needs a leg per requirement (cp1 F2).
- cp1: each per-commit review minor became its own row (most of 27 to 44); bundle a stage's minors into its next row unless they touch a gate.
