---
title: Editing text
description: Type and format text in a text element or inside a shape, with keyboard shortcuts and Markdown shortcuts.
---

Text lives in text elements, in shapes (a shape's label) and on connectors. Double-click an element, or select
it and press **Enter** (or **F2**), to edit its text in place. The text is saved when you click outside it or press
**Esc**; the whole edit is one undo step in the document. A shape set to *Fit: grow* grows to hold what you type in
the same step.

## Formatting

| Do this | Keys |
|---|---|
| Bold | `Ctrl+B` |
| Italic | `Ctrl+I` |
| Underline | `Ctrl+U` |
| Undo, redo while editing | `Ctrl+Z`, `Ctrl+Y` |
| A line break inside a paragraph | `Shift+Enter` |
| Nest, or lift, a list item | `Tab`, `Shift+Tab` |

Select text first to format it, or press the shortcut and keep typing to format what comes next.

## Markdown shortcuts

Type these at the start of a line, or around a word; they turn into formatting as you type the closing mark:

| Type | You get |
|---|---|
| `# ` to `###### ` | a heading of that level (one to six) |
| `- ` or `* ` | a bullet list item |
| `1. ` | a numbered list item |
| `**bold**` | **bold** |
| `_italic_` | *italic* |
| `` `code` `` | inline code |

Press **Enter** to start the next list item or paragraph. If a shortcut fires when you did not mean it,
the first `Backspace` after it gives the characters you typed back.

## Text and layout

A shape's *Fit* setting (none, shrink or grow) says what happens when its text does not fit, and *Auto size* on a
text element makes it follow its width or height. [Keyboard shortcuts](/guides/keyboard-shortcuts/) lists every
other key.
